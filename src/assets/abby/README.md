# Abby empty-state artwork

These are unmodified transparent PNGs from the approved **Abby-10-transparent-PNGs.zip**, version 1 (Library `libfile_a782dfcf2c708191854af91613632866`).

- `curious-sniff.png`: variant 7, the revised pose sniffing the air. Used for first launch and an empty People list.
- `dates-companion.png`: variant 4. Used on Upcoming when people exist but no dates are saved.
- `first-note.png`: variant 3. Used in an empty Facts section.

The shared `Abby` component sizes the original transparent canvas without recoloring the charcoal lines or adding a background. Artwork is decorative and hidden from accessibility navigation; the adjacent text and actions carry the meaning.
