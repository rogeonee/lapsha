# Lapsha, a little further

Open `index.html` in a browser. The report is a single self-contained file with embedded fonts and artwork; it works offline. Source links require an internet connection. It does not run analytics or transmit calculator inputs.

The report includes:

- 19 comparisons across personal notebooks, CRMs, gifting and adjacent products.
- A practical “borrow / improve / prove it” playbook.
- Six development directions and a broader household / keepsake vision.
- Spotify and Apple Music feasibility based on current official documentation.
- Three interactive visual concepts and an adjustable paid-once economics model.
- A proposed six-week validation plan, 38 source groups and the subagent debate.

Research snapshot: 19 September 2026. This is public desk research, not customer validation or hands-on competitor benchmarking. Proposed prices, revenue scenarios and experiment thresholds are explicitly hypothetical.

`sources.json` is the structured evidence ledger. The four `*-notes.md` files preserve the research partners’ workpapers and dissent; the HTML is the final synthesis. `FONT-LICENSES.txt` contains the embedded fonts’ license notices, also included inside the HTML.

Verification: browser checks at 320, 390, 768 and the default 1470-pixel viewport; competitor filtering; all visual variants; detail expansion; calculator base case, changed conversion, zero conversion and 30% fee; internal anchors; embedded assets; JavaScript syntax; no runtime network assets. These are web-report checks, not native app/device verification. Print styles are included; no separate PDF is delivered.

The report is independent of the app’s implementation. The report’s editorial typography and green palette are intentional; the native UI specimens retain system type. The approved Abby reference is reused without editing.
